# kintone カスタマイズ — ガチャトン

指パッチンを3回検出すると、現在の一覧ビューからランダムにレコードを1件選んで詳細画面に遷移する kintone カスタマイズです。

## セットアップ

1. kintone アプリの設定 → JavaScript/CSSでカスタマイズ を開く
2. 以下の順番でJSファイルをアップロード:
   1. `sound-detector.js`（ライブラリ）
   2. `noise-picker.js`（カスタマイズ本体）
3. 保存してアプリを更新

**アップロード順が重要です。** `sound-detector.js` を先に読み込む必要があります。

## 使い方

1. アプリの一覧画面を開く
2. 右下にガチャトンウィジェットが表示される
3. マイクへのアクセスを許可
4. 指パッチンを3回鳴らす（ドットが1つずつ光る）
5. ランダムに選ばれたレコードの詳細画面に遷移

## カスタマイズ

`noise-picker.js` 内の定数で動作を調整できます:

- `REQUIRED_DETECTIONS` — 必要な検出回数（デフォルト: 3）
- `PROFILE` — 検出する音のプロファイルデータ（埋め込み済み）
